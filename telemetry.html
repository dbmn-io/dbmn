What We Never Collect

None of the following ever leaves your machine:
  • An environment's address, or an API's method or path
  • Request or response bodies
  • Auth tokens or credentials
  • CSV, JSON, or Excel file contents
  • Headers, query parameter values, or the values in a path
  • The names of your saved endpoints
  • Individual record data
  • Error message content (only success/failure counts)

How It Works

  • Only while you are signed in to a DBMN account
  • Only from DBMN for VS Code. The web app and the desktop app send none
  • Counters are added up on your computer into one total per day, whichever environment or API you ran against
  • Flushed to the server every 5 minutes
  • The server identifies you via auth.uid() — no user ID is sent from the client
  • Row-Level Security: you can only ever see your own data
  • View your stats on your Account dashboard

Your API Data Stays Local

  • Requests, responses, and logs are saved in your Dobermann workspace folder (~/Dobermann-Workspace by default)
  • Credentials are stored in your OS-level credential manager (Keychain / Windows Credential Manager)
  • None of it is sent to us

Need Zero Telemetry?

Turn off Share usage counts with DBMN under Account → Weekly Usage, or turn off VS Code's own telemetry setting, or stay signed out: signed out, nothing is sent. See Usage telemetry.

Check It Yourself

Dobermann is open source. The exact fields are listed in TELEMETRY.md in the repository, and a test there fails if the code and that file disagree.
